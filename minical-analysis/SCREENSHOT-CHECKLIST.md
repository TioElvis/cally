# Screenshot checklist

minical can't run on this Mac, so take these on an **iPhone** (and an iPad if you have one). Put them in `screenshots/`.

## How to capture
- **File names:** `NN-screen-state-mode.png`, e.g. `02-home-default-light.png`, `02-home-default-dark.png`. Use the numbers below.
- Use a test calendar with a **realistic mix** of events: several per day on some days, a multi-day event, all-day events, a recurring event, an event with location + URL + notes + a Zoom link, an event with attendees, a birthday, a holiday, past events this month, and 2–3 calendars in different colors.
- For each screen, capture **light** and **dark** unless marked "(light only)".
- For gestures and animations, a short **screen recording** (`.mov`/`.mp4`) is very valuable: month swipe, opening the editor, the FAB menu, long-press, drag.
- Free version first. If someone has Pro, capture the Pro-only items marked ★ too.
- Make sure no personal data from real calendars shows. Use test events only.
